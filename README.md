# Shir Bar

Hi! I'm Shir, I'm a PhD candidate at Tel Aviv University's School of Zoology, co-advised by Prof. Roi Holzman (Zoology) and Prof. Shai Avidan (Electrical Engineering).
I'm intereseted in how we can use recent advances from the field of computer vision to advance ecological research. 

I've been mostly fiddling around with animal behavior data (video, landmark-based kinematics, accelerometery), asking how we can get at finding behaviors of interest, which in most cases will not be what the animals we observe do most of the time. Currently, I'm working on different challenge, trying to build a single system to assess morphological landmarks of interest across the morphological diversity of reef fishes, which is quite astonishing
